# دفتر درجات الإنكليزي

سجل درجات عربي RTL للمدرسين. يضم الدرجات الشهرية وكشوف نصف السنة ونهايتها، البحث في الشعب، الاستيراد والتصدير، متابعة الطالب، مراجعة التسليم، التقارير والطباعة والشهادات، وأرشفة السنوات.

## تشغيل مجاني على الحاسبة

يتطلب Node.js 22.13 أو أحدث. من مجلد المشروع شغّل:

```sh
npm ci --ignore-scripts
npm test
node scripts/build.mjs
node scripts/local.mjs
```

افتح `http://127.0.0.1:4173/`. تُحفظ بيانات هذه النسخة في قاعدة SQLite محلية داخل `.local/`. الخادم المحلي مخصص لهذا الجهاز، ويستمع على عنوان الحلقة المحلية فقط. نسخة الموقع المستضافة تستخدم هوية الحساب وقاعدة D1 للمزامنة بين الأجهزة. استضافة نسخة مستقلة على الإنترنت تتطلب موفر مصادقة وتخزين مناسبين. GitHub Pages يستضيف ملفات ثابتة ويحتاج خادماً منفصلاً لتشغيل المزامنة.

## استخدام الجدول

- اسم الطالب ورقمه ورأس الجدول تبقى ظاهرة أثناء التمرير.
- على الهاتف مرّر داخل الجدول لعرض الدرجات والأدوات الباقية.
- استخدم Tab للتنقل، وأعلى/أسفل أو Enter للانتقال بين الطلاب. الأسهم الأفقية تنقل التركيز بين الخلايا عند طرف النص.
- انسخ نطاقاً من Excel، ثم الصقه في أول خلية مناسبة. النطاق يُفحص بالكامل قبل الحفظ. أعمدة المجموع والشفوي المحتسب وأزرار الأدوات تُتجاوز، والدرجات الفارغة تُترك فارغة.
- افتراضيًا يُعرض «راسب» للدرجة الكاملة الأقل من حد الرسوب 50. الغياب والتأجيل والخانات الناقصة لا تُعامل كصفر.

### واجهة دفتر الدرجات

تعرض الواجهة الأصلية أعمدة المهارات `Listening` و`Reading` و`Speaking`، وتدعم التمرير داخل الجدول واللصق من Excel. وضع «إدخال سريع» متاح لإدخال درجات طالب واحد. خط [Zain](https://github.com/googlefonts/zain) مضمن محلياً بالملفات العربية واللاتينية وترخيص SIL Open Font License في `public/fonts/`.

## الرئيسية واستيراد الأسماء

- الرئيسية تعرض مدخلين: دفتر الدرجات واستيراد الأسماء. بقية الأدوات في قوائم «إدارة الدفتر»، «إعداد الصف»، «إضافة كشف» و«أدوات الدرجات».
- الاستيراد يدعم XLSX وXLS وODS وCSV وTSV وTXT وWord DOCX وPDF النصّي. اختر الصف والورقة وعمود الاسم وأول صف، ثم عدّل كل اسم أو أزله قبل الإضافة. الحد ١٢ ميغابايت و٢٠٠٠ اسم في الدفعة، و٣٠ صفحة لملفات PDF. ملف Word القديم DOC غير مدعوم؛ احفظه DOCX.
- قارئ الصور يدعم العربية والإنكليزية داخل المتصفح باستخدام Tesseract.js. أول استعمال يحتاج إنترنت لتنزيل نموذج اللغة المجاني من jsDelivr. الصورة لا تُرفع إلى خدمة OCR. جودة التصوير والخط تؤثر في الدقة؛ المراجعة اليدوية ضرورية. ملفات PDF المصوّرة تحتاج رفع صفحات الأسماء كصور.
- تتجاوز الأداة الأسماء المتكررة افتراضياً، مع خيار السماح بالتكرار. تُضاف الأسماء إلى أشهر الصف وكشوف امتحاناته بمعرّف ثابت لكل طالب، وتُحفظ الدرجات السابقة.
- حزم PDF وWord ومحرك OCR مضمنة في الخادم عند البناء. لا توجد مفاتيح API أو خدمات OCR مدفوعة.
